## Ejecución Local

Para ejecutar el proyecto y ver la documentación interactiva (Swagger):

1.  Instalar dependencias: `npm install`
2.  Configurar `.env` (ver `.env.example`)
3.  Iniciar servidor: `npm run start:dev`
4.  Swagger UI: [http://localhost:3000/api](http://localhost:3000/api)
